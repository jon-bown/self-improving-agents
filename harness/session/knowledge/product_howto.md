# Product how-to (Acme Cloud)

## Exporting data
- Settings → Data → Export. Formats: CSV or JSON.
- Large workspaces can take up to 24 hours; you get an email when the export is ready.

## Teammates
- Workspace → Members → Invite.
- Pro plan: up to 10 seats. Enterprise: unlimited seats. Free: 1 seat.

## API keys
- Settings → Developer → API keys. A key is shown only once, at creation.

## Integrations
- Built-in integrations: Slack, GitHub, and Google Drive. There is no Jira integration.

## Offline mode
- Offline mode is available in the desktop app only, not in the browser or mobile apps.
